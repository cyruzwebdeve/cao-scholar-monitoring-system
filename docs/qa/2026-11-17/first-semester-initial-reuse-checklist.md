# First-semester document reuse checks

Prepared 2026-11-17. Use synthetic Scholar records and files. These manual checks have not been performed on live records.

Start with a Scholar whose approved initial COG and Registration Form belong to the selected academic year's 1st Semester. CAO must approve the other required initial documents and open continuing uploads.

| Check | Action | Expected result |
| --- | --- | --- |
| 1 | Open Continuing requirements without uploading new COG or Registration Form. | Both approved initial files appear with a Reused from initial documents note. They count as approved continuing evidence. No duplicate continuing files are saved. |
| 2 | Click View on both reused files. | Each opens the actual initial document. |
| 3 | Replace the COG while continuing uploads are open. | The new COG is Pending review. The original initial COG stays intact; Registration Form remains reused and Approved. |
| 4 | Approve the replacement in the admin document review. | Continuing counts show the approved replacement plus reused Registration Form. Staff view/review targets the replacement's continuing version. |
| 5 | Return/reject a replacement, then reopen Continuing requirements. | The returned file and correction message remain; the old approved initial file does not hide the rejection. Upload again is available while submissions are open. |
| 6 | Reupload an already approved continuing file. | Replace is available while uploads are open. The new version becomes Pending; the previous continuing version remains in history. |
| 7 | Close continuing uploads in Settings, then try replacing a file. | Existing files remain viewable. Replacement is unavailable and direct upload requests are rejected. |
| 8 | Select the 2nd Semester or a later academic year's 1st Semester. | The old initial COG and Registration Form are not reused. That period needs its own continuing files. |
| 9 | Check a first-year initial set with an approved Grade 12 report card but no college COG. | Registration Form can be reused; continuing COG is still missing. Report card does not substitute for college grades. |
| 10 | Check a Private-school Scholar. | Reuse applies to COG and Registration Form only. Continuing tuition receipt rules stay unchanged. |
| 11 | Review the same record in admin Overview and Reports; try a bad file or change period during file preparation. | Overview shows the correct initial source/version for reused evidence and continuing source/version for replacements. Reports clears only recorded sets with approved evidence; recorded activity and payroll-list amounts remain unchanged. Invalid/stale uploads do not replace files or overwrite another period's screen. |

Also check initial COG/Registration Form files that are missing, Pending, Returned or have no usable stored content: they must not be reused as approved continuing files. A different or ambiguous initial source must not be guessed.
